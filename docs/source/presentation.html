MoveWire · 04 / 10

The AI does useful work

Useful tools with clear limits.

Compare tuition routes · Simulate rent changes · Test currency changes · Prepare a payment proposal. Save requested planning edits; confirm declared funding changes.

The model has no approval or execution capability. Each tool uses the logged-in student’s records.
MoveWire · 05 / 10

Protect time and living costs

The cheapest route must also meet the student’s plan.

The app checks quote expiry, delivery time with a safety buffer, and available cash. It checks the deadline and living reserve before preparation and again before sending.

Blocked routes explain the funding top-up. UTC weekdays exclude holidays and university processing; arrival is an estimate.
MoveWire · 06 / 10

Approval means exact terms

One proposal. One recipient. One quote.

Student approval covers provider, recipient, rate, fee, amount, expiry, deadline and reserve. Provider changes require reset and fresh approval.

Source quotes expire in ten minutes; proposal expiry never extends them. AI preparation never grants authority to pay.
MoveWire · 07 / 10

Execution you can inspect

A receipt backed by a financial ledger.

The wallet debit, ledger entry, receipt, and audit record are saved together. Sending again returns the same receipt without another debit.

Chat shows recorded calculations. Evidence exports include proposals, tool results, actor timestamps and before/after balances. No external settlement is claimed.
MoveWire · 08 / 10

Privacy and security

Students control sponsor access and AI processing.

Students choose sponsor access · AI consent can be withdrawn · API keys stay on the server · Only approved tools run · Account and daily limits.

Known limits: no MFA, no real payee/KYC verification, AI explanations can be wrong and no independent security audit.
